## 1. 报告目标

报告必须同时服务三类读者：

- 决策者：快速知道项目值不值得继续看。
- 产品与业务人员：理解客户、场景、功能和实际价值。
- 技术人员：理解架构、数据流、依赖、限制和验证证据。

主报告不能只有产品介绍，也不能只有源码笔记。

## 2. 必需章节

### 0. 文档信息与证据口径

记录对象、来源、固定版本、日期、产品形态、许可证、范围和证据标签。

### 1. 项目概览

包含：

- 一句话定位：“面向谁，在什么场景，通过什么能力，实现什么结果。”
- 核心信息卡。
- 最值得关注、最适合、不适合、最大限制、采用前验证。

### 2. 客户、问题与场景

写出目标角色、原流程、具体痛点、触发条件、成功标准。至少两个典型场景，不把“所有开发者”当作客户描述。

### 3. 功能体系

写功能全景、核心功能表和完整用户流程。每项功能至少包含输入、处理、输出、价值、异常和证据。

### 4. 实际场景案例

至少两个，遵循“案例合同”。

### 5. 核心技术实现

写总体架构、执行链、核心模块、数据生命周期、并发/超时/重试、幂等/恢复、日志/监控和容量边界。无运行时的项目说明为什么不适用。

### 6. 第三方能力

列用途、调用位置、传输数据、鉴权、成本、替代/降级和失败影响。

### 7. 边界与限制

覆盖功能、平台、格式/大小/并发、未验证、安全、隐私、许可和成熟度。

### 8. 使用、部署与运维

覆盖最小使用路径、配置、部署、日志、升级、回滚和常见故障。资料库或 Skill 改写为实际消费方式和宿主要求。

### 9. 评价与选型

列优势成立条件和对应代价，区分推荐采用、建议试点、研究教学、当前不建议，并给出二次开发建议。

### 10. 其他注意事项

覆盖动态信息、版权商标、AI 不确定性、网络地区硬件和未确认事项。

### 11. 证据与参考

关键结论必须能回到固定文件、官方页面、测试输出或运行记录。

### 12. 最终结论

用七个短答案收束：项目本质、最适合解决、核心机制、最大优势、最大限制、采用条件、仍需验证。

## 3. 功能与架构深度

功能分析合格的最低标准：

- 不只列功能名，要解释用户何时触发。
- 不只列输入输出，要解释中间状态和反馈。
- 不只写成功路径，要写失败、重试、取消或恢复。
- 不只写“支持第三方”，要解释数据和鉴权边界。

架构分析合格的最低标准：

- 找到真实入口和核心模块。
- 画出或文字描述端到端数据流。
- 说明状态保存在哪里、生命周期如何结束。
- 说明外部依赖失败时发生什么。
- 区分仓库已有机制和研究者建议。

若源码规模过大，优先深挖决定核心价值的 3–7 个模块，不用逐文件复述。

## 4. 案例合同

每个案例必须有以下字段：

| 字段 | 要求 |
| --- | --- |
| 案例类型 | 官方案例 / 本地验证 / 场景推演 |
| 背景与用户 | 具体角色、任务和冲突 |
| 前置条件 | 环境、数据、权限或配置 |
| 真实输入 | 文件、请求、提示词、事件或数据形态 |
| 操作步骤 | 有顺序的用户动作 |
| 内部处理 | 入口、模块、状态、第三方 |
| 结果与价值 | 可观察输出和对工作流的改变 |
| 异常与边界 | 失败条件、风险和恢复 |
| 验证证据 | 文件、链接、测试或“推演依据” |

两个案例不能只替换用户名字。它们应覆盖不同角色、不同入口、不同成功目标或一个成功路径与一个异常/恢复路径。

## 5. 第三方与边界

必须把以下概念分开：

- “本地运行”与“数据不出本机”。
- “代码开源许可”与“内容、字体、图片、音频、商标权利”。
- “官方声称支持”与“本次验证通过”。
- “有测试文件”与“测试覆盖核心路径”。
- “能运行 Demo”与“可生产运行”。
- “Skill 指令完整”与“真实任务效果好”。

高风险项目还应覆盖权限、secret、上传下载、日志脱敏、数据删除、供应链和回滚。

## 6. 总目录合同

总目录必须包含：

1. 更新时间、研究对象数、主报告数和多报告口径。
2. 一屏总览表：项目、类型、用户/场景、核心实现、成熟度、建议、链接。
3. 按用户需求或决策问题分组的快速选择。
4. 至少三条跨项目共性结论。
5. 动态指标、未运行能力和建议性质的研究边界。

总目录是决策入口，不是把每份报告摘要简单拼接。

## 7. 完成审计

逐项取证：

- 项目数是否来自冻结清单。
- 主报告链接是否存在。
- 每份报告是否有两个完整案例。
- 关键功能是否绑定证据。
- 架构是否覆盖入口、模块、状态和失败。
- 第三方是否覆盖数据、鉴权、成本和降级。
- 未验证项是否明确。
- 自动校验是否真正覆盖本次全部报告。

缺少直接证据的要求不能标记完成。
