# PRD：公众号公网情报监控 Skill

## 1. 产品目标

让用户用一个可安装的 Codex Skill 管理目标公众号列表，通过免费公网来源优先发现文章更新，并对新文章形成可追溯摘要和来源健康报告。

产品承诺的是“诚实的可观察性”，不是免费源无法提供的完整性保证。

## 2. 核心使用场景

### 2.1 首次配置

1. 用户提供公众号名称、`wxid`、`biz` 和已知公开入口。
2. Skill 生成 JSON 配置示例。
3. CLI 在联网前验证字段、URL 协议、重复 ID 和来源所需参数。
4. 配置有效后才执行发现。

### 2.2 单次检查

1. 用户运行监控命令。
2. 系统读取各来源并记录每个来源的成功、零结果、失败或被阻断状态。
3. 系统校验公众号归属、时间窗口和唯一键。
4. 系统读取新文章正文；异常页不进入摘要。
5. 输出 JSON/Markdown 报告。
6. Agent 根据报告中的有效正文生成中文摘要。

### 2.3 定时监控

1. 用户先执行一次 dry run 和联网 smoke test。
2. Skill 生成 cron 行或推荐使用 Codex Automation。
3. 周期任务使用运行锁、超时、抖动和回看窗口。
4. 每晚扩大回看窗口，补偿来源延迟。
5. 来源全部失败时发送“监控盲区”，而非“没有更新”。

## 3. 来源优先级

1. 微信公开 Album：免费、无需登录；仅覆盖被加入该合集的文章。
2. 微信公开 Homepage：免费、无需登录；仅覆盖公开主页模板/栏目。
3. 发布方 RSS/Atom/官网：免费、独立但不一定与公众号同步。
4. 已知微信文章 URL：用于正文和身份校验，不是发现 feed。
5. 远程商业 API：通过后续 adapter 接入，用于提高召回率；不作为默认免费能力。

## 4. 状态模型

### 来源状态

- `ok`：请求和解析成功。
- `observed_zero`：请求成功但在窗口内没有候选。
- `blocked`：命中验证码、环境异常、登录页或明确风控页。
- `source_unavailable`：网络、HTTP、schema 或上游错误。
- `invalid_config`：配置错误，未发起请求。

### 覆盖状态

- `high_confidence`：两个独立来源均健康且结果一致或可解释。
- `partial`：至少一个来源健康，但没有完整性承诺。
- `unknown`：所有来源失败、被阻断或配置无效。

默认免费源不得输出 `complete`。

## 5. 摘要行为

- 自动化脚本生成 `summary_input` 和确定性 `summary`，来源于文章描述或通过质量门禁的正文摘录，并标注 `summary_basis`。
- Codex 调用本 Skill 时生成 3–5 条中文要点和一句情报意义。
- 不确定内容明确标注；不得根据标题补写事实。
- 摘要失败不阻止输出标题、时间和原文链接。
- 不批量转载全文；只保留必要摘录、hash 和来源链接。

## 6. 异常、空态和回滚体验

- 配置错误：返回退出码 2，列出具体字段。
- 某来源失败：其它来源继续；报告降级为 `partial` 或 `unknown`。
- 所有来源成功但零结果：报告 `observed_zero`，并说明不能证明全网无更新。
- 正文被阻断：保留文章元数据，`content_status=blocked`，不生成伪摘要。
- SQLite 写入失败：本次运行失败，不推进 checkpoint。
- 回滚：删除本 Skill 的 Codex 安装链接即可；运行状态由用户指定目录独立保留。

## 7. 权限和安全

- 默认只访问 `https://` URL。
- 不读取浏览器 Cookie、微信 Token 或本机微信目录。
- 可选 provider key 只从环境变量读取，禁止出现在配置、日志和报告。
- 带环境变量鉴权 header 的 provider 请求若跨 origin 重定向，立即阻断，不把凭据转发到新主机。
- 非法环境变量 header 在请求前以脱敏错误拒绝，不把 header 值写入报告或状态库。
- 每次 HTTPS 连接只解析一次 DNS，并连接到已校验为公网的解析地址；禁用环境代理，避免绕过目标校验。
- 日志不写正文全文和 secrets。
- 默认串行或低并发，请求设置超时、响应大小上限和明确 User-Agent。
- 单次运行有总 deadline；目标、来源、候选和 SQLite 运行证据均受容量或保留期限制。
- 配置仅接受有大小上限的普通文件，初始读取受独立 deadline 保护；cron 路径拒绝换行、NUL 和 `%`。
- 同一文章被多个监控目标引用时，按 `(target_id, article_key)` 独立保存和告警。

## 8. 兼容性路径

- 不修改现有 PolaNews、其它 Skill 或现有定时任务。
- 不改变任何旧 API、旧数据、旧 UI、历史记录、登录态、下载/上传路径。
- 运行数据全部写入用户指定工作目录。

## 9. 验收

验收项以需求文档 A1–A12 为准。核心产品路径必须由离线 harness 和至少一个公网 smoke test共同验证。
