# PRD：pola-wechat-record-export V2

## 用户流程

1. 用户准备本机离线解密副本。
2. Agent 只读发现 message/biz_message/sns 数据源并预览范围。
3. 用户选择时间范围与明文/哈希身份模式。
4. 导出统一时间线和机器格式。
5. Agent 回读 manifest，报告计数、范围、缓存边界和验证结果。

## 异常与空态

- 输入缺失：停止并指出缺少的目录或文件。
- schema 不匹配：fail closed，不猜测。
- 无朋友圈：聊天仍可独立导出，manifest 不伪造朋友圈计数。
- 超过上限：停止，要求显式扩大限制或缩小时间范围。
- 重名会话：稳定 record id 和来源元数据避免覆盖与重复。

## 兼容

保留原 `export_all.py`、解密工具和 TXT 流程；新统一导出是附加入口。旧数据、微信登录态和应用均不改变。
